URL Shortener

Paste a long link, get a short one back. Click it to jump straight to the original.

This runs entirely in your browser as a demo of the flow — links only resolve in this tab, and reset on refresh. A real version would swap this in-memory list for a Laravel API + database, so short links work for anyone, from any device.
