The short version

I like building software that reacts live — quizzes that count down in real time, forums that push replies the instant they're posted, dashboards that sync across devices. Most of my recent work has been on a Laravel-based educational platform and a JavaFX desktop app with offline-first sync.

Outside of client-style work, I'm always shipping a side project — right now that's Atomic Life, a React app that turns "things I want to add to my life" into an actual daily schedule.

I'm now opening up to freelance and contract web work — if you need a site or web app built properly, from the database up, let's talk.
